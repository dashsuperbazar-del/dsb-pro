# DSB Pro — how to open it in the shop

Old DSB was one `index.html` file. DSB Pro is an installable app: open the link once, install it, and from then
on it opens from the home-screen icon like old DSB, and keeps working offline.

## Open and install (once per phone/PC)

1. Open **https://dsb-pro.pages.dev/** in Chrome (backup address: https://dashsuperbazar-del.github.io/dsb-pro/).
2. Sign in with your owner account.
3. Chrome menu (⋮) → **Install app** / **Add to Home screen**.
4. Use the **DSB Pro** icon from now on. Updates arrive by themselves; reopen the app to get them.

## Offline

- Sales and purchases entered offline are saved on the phone and sent when the internet returns.
- Money requests show "awaiting server confirmation" until the server accepts them; nothing is lost.

## New in this release

- Camera barcode scan (POS and purchases), voice entry for purchase lines.
- Quick bill, batch entry and "Fill from CSV", resizable bill viewer.
- Supplier payment schedule reminders, bulk supplier payments, price history.
- **Merge duplicate supplier** (Suppliers → supplier → "Merge into another supplier…"):
  shows what moves, keeps both suppliers' records, archives the duplicate, then lists identical bills for you to
  void by hand. Refused if both have an opening balance in the same shop.
